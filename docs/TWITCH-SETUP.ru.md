# Настройка Twitch в StreamBridge

Для передачи видео достаточно ключа потока. Для общего чата, счётчика зрителей и модерации нужно подключить аккаунт Twitch.

Для подключения один раз зарегистрируйте своё приложение Twitch и получите его **Client ID**. Этот идентификатор не является паролем или ключом трансляции.

## 1. Подготовьте аккаунт

1. Войдите в аккаунт Twitch, с которого планируете вести трансляции.
2. Убедитесь, что почта аккаунта подтверждена.
3. Включите двухфакторную аутентификацию в настройках безопасности Twitch.
4. Откройте [консоль приложений Twitch](https://dev.twitch.tv/console/apps).

Подтверждённая почта и двухфакторная аутентификация необходимы для регистрации приложения. [Требования Twitch](https://dev.twitch.tv/docs/authentication/register-app/).

## 2. Зарегистрируйте приложение

Нажмите **Зарегистрировать приложение** и заполните форму:

| Поле | Что указать |
| --- | --- |
| Название | Уникальное имя, например **StreamBridge_ВашНик**. Если занято, добавьте цифры. |
| OAuth Redirect URLs | Введите **https://localhost** целиком и нажмите **Добавить**. Убедитесь, что адрес появился в списке. |
| Категория | Выберите **Application Integration**; если такого пункта нет — **Другое**. |
| Тип клиента | Выберите **Виден всем**. Это тип Public, необходимый для входа в StreamBridge. |

Пройдите CAPTCHA, если она появилась, и нажмите **Создать**.

Адрес **https://localhost** нужен для заполнения формы регистрации. StreamBridge входит через код устройства: при таком способе Twitch не перенаправляет браузер на этот адрес. Открывать localhost, запускать веб-сервер или устанавливать сертификат не нужно. [Описание входа по коду устройства](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow).

## 3. Укажите Client ID в OBS

1. Вернитесь к списку приложений Twitch.
2. Рядом со своим приложением нажмите **Управление**.
3. Скопируйте **Client ID**.
4. В OBS откройте **Настройки StreamBridge → Twitch**.
5. Раскройте **Настройка подключения · Client ID** и вставьте скопированное значение в поле **Client ID**.

Не вставляйте туда ключ трансляции. Создавать и копировать **Client Secret** для этого способа подключения не требуется.

## 4. Подтвердите подключение в браузере

1. Нажмите **Подключить аккаунт Twitch**.
2. В настройках OBS появится короткий код, а в браузере откроется страница активации Twitch.
3. Если сайт просит код, нажмите **Скопировать код авторизации Twitch** в плагине и вставьте его на сайте.
4. Проверьте, что в браузере открыт нужный аккаунт канала.
5. Проверьте название приложения и предоставьте запрашиваемые разрешения.
6. Вернитесь в OBS и дождитесь **Аккаунт подключён**.

Оставляйте настройки OBS открытыми до завершения подключения. Плагин сам получает результат; переход на localhost не нужен. Если вкладка браузера не открылась, нажмите **Снова открыть сайт авторизации**.

## 5. Получите ключ и запустите трансляцию

1. На вкладке **Twitch** нажмите **Использовать ключ этого аккаунта**.
2. Дождитесь сообщения о сохранении сервера и ключа. Вручную копировать ключ после этого не нужно.
3. Проверьте настройки кодирования и нажмите **Сохранить** внизу окна.
4. В основной панели StreamBridge нажмите **Запустить** рядом с Twitch.
5. Откройте [кабинет автора Twitch](https://dashboard.twitch.tv/) и проверьте получение сигнала.

Подключение аккаунта само по себе не запускает эфир. Кнопка Twitch в StreamBridge управляет отдельным выходом независимо от основной кнопки трансляции OBS.

## 6. Включите чат

1. В меню OBS **Док-панели** включите **StreamBridge — Чат**.
2. Чат подключается автоматически. Дождитесь зелёного **Twitch · Online**. При ошибке наведите курсор на статус; кнопка со стрелкой переподключает чат.
3. Сообщения Twitch выделены фиолетовым фоном, ники — жирным; рядом значки ролей. Смайлики Twitch и BetterTTV, включая GIF, загружаются автоматически. Нажмите на ник для карточки: дата отслеживания требует повторной привязки Twitch с разрешением `moderator:read:followers`. Звук выбирается в **Настройки StreamBridge → Настройки**: выключен, Astra или локальный PCM WAV; там же громкость и прослушивание.
4. Для модерации нажмите сообщение правой кнопкой. Требуются права владельца канала.

Отдельная панель данных удалена. Название, описание, категорию и текст уведомления меняйте в [кабинете Twitch](https://dashboard.twitch.tv/).
## Если не получается

| Сообщение или проблема | Что сделать |
| --- | --- |
| «URL-адреса должны использовать протокол HTTPS» | Укажите **https://localhost** без пробелов и нажмите **Добавить**. |
| Кнопка создания приложения неактивна | Проверьте название, выбранную категорию, добавленный адрес, CAPTCHA, подтверждение почты и двухфакторную аутентификацию. |
| Ошибка авторизации до появления кода | Проверьте, что приложение имеет тип **Виден всем**, а в OBS вставлен его **Client ID**. |
| Браузер не открылся | Нажмите **Снова открыть сайт авторизации** в настройках плагина. |
| Код истёк | Отмените попытку и снова нажмите подключение. Используйте новый код. |
| Настройки OBS закрылись во время входа | Начните подключение заново и оставьте окно открытым до завершения. |
| Подключился другой канал | Отключите аккаунт в StreamBridge, смените аккаунт на сайте Twitch и повторите подключение. |
| Чат не загружается | Проверьте подключённый канал и **Автоматически подключать чаты** во вкладке **Настройки**. Прочитайте статус Twitch над сообщениями. |
| Модерация недоступна после обновления | Переподключите аккаунт для выдачи актуальных разрешений. У аккаунта также должны быть права на действие. |
| Видео не начинается | Получите ключ кнопкой **Использовать ключ этого аккаунта**, сохраните настройки и проверьте состояние выхода в основной панели. |

## Если нужен только видеопоток

Этот вариант не требует регистрации приложения Twitch:

1. Откройте [кабинет автора](https://dashboard.twitch.tv/) → **Настройки → Трансляция**.
2. Скопируйте основной ключ потока.
3. В **Настройки StreamBridge → Twitch** выберите автоматический сервер.
4. Вставьте ключ в **Ключ трансляции** и нажмите **Сохранить сервер и ключ (с шифрованием)**. После сохранения поле очистится.
5. Нажмите **Сохранить** внизу окна.
6. Нажмите **Запустить** рядом с Twitch и проверьте сигнал в кабинете автора.

Этот способ передаёт видео, но не подключает чат, зрителей через API. Не публикуйте ключ трансляции или токены аккаунта.
