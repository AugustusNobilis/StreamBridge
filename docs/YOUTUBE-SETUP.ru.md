# Настройка YouTube в StreamBridge

Инструкция рассчитана на **StreamBridge 0.2.3 или новее**. Для передачи видео достаточно ключа потока. Для общего чата, счётчика зрителей и изменения данных эфира нужно подключить аккаунт через собственный проект Google Cloud.

Каждый пользователь создаёт свой проект. Для личной настройки не нужно публиковать приложение для всех пользователей или передавать автору плагина данные аккаунта.

## 1. Подготовьте проект Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) под своим Google-аккаунтом.
2. В верхней части страницы нажмите название текущего проекта. Выберите существующий проект для StreamBridge или создайте новый через **New project**.
3. Убедитесь, что в верхней строке выбран нужный проект. Все дальнейшие действия выполняйте в нём.
4. Откройте **APIs & Services → Library**.
5. Найдите **YouTube Data API v3**, откройте его страницу и нажмите **Enable**. Если вместо этого видна кнопка **Manage**, API уже включён.

## 2. Разрешите вход своему аккаунту

1. Откройте **Google Auth Platform**. Если настройка ещё не выполнена, нажмите **Get started**.
2. Укажите название, например **StreamBridge**, почту поддержки и контактную почту.
3. Для личного Google-аккаунта выберите аудиторию **External** и завершите начальную настройку.
4. Откройте **Audience**. Для личного использования на этапе настройки оставьте статус **Testing**.
5. В блоке **Test users** нажмите **Add users** и добавьте email аккаунта, которым будете входить в YouTube. Сохраните изменения.
6. Откройте **Data Access → Add or remove scopes**. Добавьте **https://www.googleapis.com/auth/youtube.force-ssl** и сохраните.

Это разрешение нужно для функций YouTube в плагине. Доступ к Gmail или Google Drive добавлять не требуется. [Инструкция Google по экрану согласия](https://developers.google.com/workspace/guides/configure-oauth-consent).

**Важно:** в режиме Testing доступ к YouTube и токен обновления истекают через **7 дней**. После этого подключите аккаунт в StreamBridge заново. Если позже захотите изменить статус публикации, сначала ознакомьтесь с [правилами Google для аудитории приложения](https://support.google.com/cloud/answer/15549945?hl=en).

## 3. Создайте клиент и сразу скачайте JSON

1. Откройте **Google Auth Platform → Clients**.
2. Нажмите **Create client**.
3. В поле **Application type** выберите **Desktop app**.
4. Введите название, например **StreamBridge Desktop**, и нажмите **Create**.
5. **Не закрывайте появившееся окно создания клиента. Нажмите в нём Download JSON и сохраните файл на компьютере.**
6. Запомните папку загрузки: этот файл понадобится выбрать в OBS.

Тип **Web application** не подходит. Для Desktop-клиента не нужно вручную указывать адрес перенаправления: StreamBridge сам открывает временный локальный адрес для ответа Google.

### Если JSON не сохранили

На странице уже созданного клиента Google скрывает полный **Client secret**. Сообщение **Viewing and downloading client secrets is no longer available** означает, что скачать прежний секрет повторно нельзя. Значение со звёздочками не подходит для настройки. [Правила Google о секретах клиента](https://support.google.com/cloud/answer/15549257?hl=en).

Для настройки StreamBridge выполните следующие действия:

1. Останьтесь **в том же проекте** Google Cloud.
2. Перейдите в **Clients → Create client** и создайте ещё один **Desktop app**, например **StreamBridge Desktop 2**.
3. Скачайте JSON сразу в окне создания, до его закрытия.
4. Используйте новый файл в следующем разделе.

Создавать новый проект, повторно включать API или заново добавлять тестового пользователя не нужно. Старый клиент можно оставить до успешной проверки подключения.

## 4. Импортируйте файл и подключите аккаунт

1. В OBS откройте **Настройки StreamBridge → YouTube**.
2. Раскройте **Настройка подключения · Client ID**.
3. Нажмите **Импортировать JSON из Google Cloud…** и выберите скачанный файл.
4. Дождитесь сообщения **Данные Desktop-клиента загружены**. Поле Client ID заполнится автоматически; вручную менять его после импорта не нужно.
5. Нажмите **Подключить аккаунт YouTube**. Откроется браузер.
6. Выберите аккаунт, добавленный в **Test users**, и нужный канал, если Google предложит выбор.
7. Проверьте название своего приложения и предоставьте запрашиваемые разрешения YouTube. Если Google показывает отдельные флажки доступа, отметьте разрешения, которые запрашивает плагин.
8. После страницы **Return to OBS StreamBridge** вернитесь в OBS и дождитесь статуса **Аккаунт подключён**.

Не закрывайте настройки OBS до завершения входа: закрытие отменяет незавершённое подключение. Локальная страница **Return to OBS StreamBridge** сама по себе ещё не подтверждает успешный вход — итоговый статус показан в плагине.

При предупреждении о непроверенном приложении продолжайте только если узнаёте свой проект и аккаунт. Отказ **403 access_denied** с упоминанием тестировщиков устраняется добавлением аккаунта в **Test users**, а не пропуском предупреждения.

JSON выбирается локально. Не отправляйте его в переписку, обращение на GitHub или другим пользователям. Одного Client ID может быть недостаточно для входа; используйте импорт полного файла.

## 5. Подготовьте эфир в YouTube Studio

1. Откройте [YouTube Studio](https://studio.youtube.com/) и убедитесь, что выбран нужный канал.
2. Нажмите **Создать → Начать трансляцию**. Если прямые эфиры ещё недоступны, выполните указанные YouTube требования активации.
3. Подготовьте трансляцию через **видеокодер**. Режим веб-камеры для отправки видео из OBS не подходит.
4. Задайте название, видимость, аудиторию и остальные параметры эфира.
5. Откройте настройки потока этого эфира и выберите ключ потока. Для запланированного эфира сначала откройте его в диспетчерской.
6. Если нужен чат, проверьте, что он разрешён для выбранного эфира.

StreamBridge использует уже созданную трансляцию. Он не создаёт эфир в YouTube Studio и не привязывает к нему поток автоматически.

## 6. Выберите эфир в StreamBridge и запустите видео

1. В настройках StreamBridge на вкладке **YouTube** нажмите **Загрузить существующие трансляции**.
2. Выберите нужный эфир из списка и нажмите **Использовать выбранную трансляцию**.
3. Дождитесь сообщения о сохранении сервера и ключа. Дополнительно копировать ключ вручную в этом случае не нужно.
4. Проверьте настройки кодирования и нажмите **Сохранить**.
5. В основной панели StreamBridge нажмите **Запустить** рядом с YouTube.
6. В панели **StreamBridge — Данные трансляции → YouTube** нажмите **Начать эфир YouTube**. Плагин проверит сигнал и дождётся подтверждения запуска. Если сигнал ещё не получен, повторите через несколько секунд.

При смене эфира остановите выход YouTube в StreamBridge, выберите новую трансляцию в настройках и снова запустите его.

## 7. Включите чат и управление эфиром

1. В меню OBS **Док-панели** включите **StreamBridge — Чат** и **StreamBridge — Данные трансляции**.
2. В чате включите **Подключить чат**. Сообщения YouTube будут отмечены значком площадки.
3. Для удаления сообщения или блокировки автора нажмите сообщение правой кнопкой. Действия доступны только при достаточных правах.
4. В панели данных выберите **YouTube** и измените название.
5. Для выбора категории укажите двухбуквенный регион, например **RU**, нажмите **Найти категории** и выберите значение.
6. Нажмите **Опубликовать название и категорию**. Существующее описание на YouTube сохраняется; его редактора в плагине нет.
7. Для категории **Игры** нажмите **Выбрать игру в YouTube Studio**. В настройках открывшегося эфира выберите название игры и сохраните. Публичный API YouTube предоставляет категорию, но не отдельное поле игры.

Чат, счётчик зрителей и данные относятся к выбранной трансляции. Запросы расходуют квоту **вашего проекта** Google Cloud. Поля описания и уведомления о стриме удалены из плагина.

## 8. Завершите эфир из OBS

1. В панели **StreamBridge — Данные трансляции → YouTube** нажмите **Завершить эфир YouTube**.
2. Проверьте название эфира в подтверждении и подтвердите завершение. Возобновить этот эфир будет нельзя.
3. Дождитесь сообщения об успешном завершении. После ответа YouTube плагин остановит свой выход YouTube; Twitch продолжит работу.

Обычная кнопка **Остановить** в основной панели прекращает отправку видео. Для явного завершения на стороне YouTube используйте кнопку **Завершить эфир YouTube**. При ошибке API выход не останавливается автоматически: проверьте сообщение и повторите действие.

## Как читать счётчик зрителей

- **0** — YouTube явно вернул ноль.
- **Число больше нуля** — полученное число одновременных зрителей.
- `0*` — эфир идёт, но поле счётчика отсутствует. Это может быть ноль зрителей или скрытая статистика; наведите указатель для пояснения.
- **—** — нет данных, эфир ещё не начался или уже завершён. Проверьте подключение аккаунта и выбранную трансляцию.

Счётчик обновляется примерно раз в минуту. Загрузка чата больше не пропускает обновление зрителей: запрос ставится в очередь. [Особенности счётчика YouTube](https://developers.google.com/youtube/v3/docs/videos#liveStreamingDetails.concurrentViewers).

## Если не получается

| Сообщение или проблема | Что сделать |
| --- | --- |
| **403 access_denied**, приложение доступно только тестировщикам | Откройте проект, которому принадлежит импортированный клиент. В **Audience → Test users** добавьте точный аккаунт входа. Отмените попытку в OBS и подключитесь снова. |
| Страница **Return to OBS StreamBridge**, затем ошибка в OBS | Убедитесь, что установлен StreamBridge 0.2.2 или новее и импортирован полный JSON Desktop-клиента. Если файл потерян, создайте новый клиент в том же проекте по разделу выше. |
| **invalid_client** или требуется **client_secret** | Проверьте, что клиент не удалён, и импортируйте его сохранённый JSON. Если сохранённого файла нет, создайте новый Desktop-клиент и сразу скачайте JSON. |
| **redirect_uri_mismatch** | Проверьте тип клиента: нужен **Desktop app**. Создайте подходящий клиент и импортируйте его файл. |
| **invalid_grant** | Отмените попытку и начните вход заново. Не закрывайте настройки OBS во время авторизации. |
| Требуется повторный вход примерно через неделю | Для YouTube в режиме Google Testing это ожидаемо. Подключите аккаунт заново. |
| Трансляций нет в списке | Проверьте канал и наличие незавершённого эфира через видеокодер. Затем снова загрузите список. |
| У трансляции нет привязанного потока | Откройте эфир в Studio, настройте его поток и ключ, затем повторите выбор в StreamBridge. |
| Ошибка API или квоты | Убедитесь, что **YouTube Data API v3** включён в том же проекте, а его квота не исчерпана. Частые повторы не восстанавливают квоту. |
| Чат пуст или счётчик показывает «—» | Проверьте выбранный эфир, состояние трансляции, разрешение чата в Studio и флажок **Подключить чат**. |

## Если нужен только видеопоток

Этот вариант не требует Google Cloud:

1. Подготовьте эфир через видеокодер в YouTube Studio и скопируйте ключ потока.
2. В **Настройки StreamBridge → YouTube** выберите основной сервер.
3. Вставьте ключ в **Ключ трансляции** и нажмите **Сохранить ключ сейчас (с шифрованием)**. Поле очистится после сохранения.
4. Нажмите **Сохранить** внизу окна.
5. Нажмите **Запустить** у YouTube в панели StreamBridge и проверьте сигнал в Studio.
6. Если автоматический старт выключен, запустите эфир в Studio вручную.

Ключ передаёт видео на площадку, но не подключает чат, зрителей и редактор данных через API.
