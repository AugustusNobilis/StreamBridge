# Twitch: настройка StreamBridge

## Что выбрать

Для передачи видео достаточно ключа потока. Для чата, зрителей, названия, категории и модерации привяжите аккаунт. В текущей версии Client ID нужно зарегистрировать самостоятельно один раз. Пароль Twitch вводится только на сайте Twitch.

## 1. Заполните форму на вашем скриншоте

Откройте [консоль приложений Twitch](https://dev.twitch.tv/console/apps) → **Зарегистрировать приложение / Register Your Application**. Для регистрации нужны подтверждённая почта и включённая двухфакторная аутентификация Twitch.

| Поле | Что указать |
| --- | --- |
| Название / Name | Уникальное название, например **StreamBridge_ВашНик**. Если занято, добавьте суффикс. |
| OAuth Redirect URLs | **https://localhost**, затем кнопка **Добавить / Add**. Адрес должен появиться в списке. |
| Категория / Category | **Application Integration** — интеграция приложения; если такого пункта нет, **Other / Другое**. |
| Тип клиента / Client Type | **Виден всем / Public**. На скриншоте выбран другой тип — переключите его. |

Пройдите CAPTCHA, если она появится, и нажмите **Создать / Create**.

Почему localhost: StreamBridge использует вход по коду устройства (Device Code Flow). Этот вход не отправляет браузер на Redirect URL; поле нужно для регистрации. Для него не нужно запускать сервер, открывать localhost в браузере или устанавливать сертификаты. Значение относится именно к реализации Twitch в StreamBridge.

## 2. Скопируйте правильное значение

1. В списке приложений найдите созданное → **Управление / Manage**.
2. Скопируйте **Client ID / Идентификатор клиента**.
3. В OBS откройте настройки **StreamBridge → Twitch → Настройка подключения · Client ID**.
4. Вставьте значение в поле Client ID. Это не ключ трансляции и не Client Secret. Генерировать Secret для этого входа не нужно.

## 3. Подтвердите вход на Twitch

1. Нажмите **Подключить аккаунт Twitch**.
2. Откроется страница активации Twitch; в плагине появится короткий код.
3. Если сайт просит код, нажмите в плагине **Скопировать код авторизации Twitch** и вставьте его на сайте.
4. Войдите аккаунтом канала, с которого будете стримить. Проверьте имя приложения и выдаваемые права, затем подтвердите.
5. Оставьте настройки OBS открытыми до статуса **Аккаунт подключён**. Возвращение на localhost не требуется: плагин сам получает результат.
6. Нажмите **Использовать ключ этого аккаунта**, если ключ ещё не получен. Дождитесь сообщения о сохранении RTMPS-настроек. Сохраните настройки.
7. В меню OBS **Док-панели** откройте **StreamBridge — Чат** и нажмите **Подключить чат**. Название и категорию меняйте в панели **StreamBridge — Данные трансляции**.

Привязка сама по себе эфир не запускает. Кнопка **Старт** в основной панели StreamBridge запускает отправку видео.

## Если не получается

- **«URL-адреса должны использовать HTTPS»**: вставьте полностью **https://localhost**, без пробелов, и нажмите **Добавить**.
- **Создать неактивна**: проверьте категорию, добавленный URL, уникальность имени, CAPTCHA, подтверждение почты и 2FA.
- **Ошибка авторизации до появления кода**: проверьте **Public** и Client ID именно этого приложения; Client Secret и ключ потока не подходят.
- **Браузер не открылся**: нажмите **Снова открыть сайт авторизации** в плагине.
- **Код истёк / настройки закрыли во время входа**: нажмите отмену, затем начните привязку заново и используйте новый код.
- **Подключился другой канал**: отключите аккаунт в плагине, смените аккаунт на сайте Twitch и повторите вход.
- **Старый аккаунт подключён, но модерация не работает**: переподключите его для выдачи новых прав. Действия доступны только при достаточных правах в подключённом канале.

## Только видео, без привязки

В [кабинете автора Twitch](https://dashboard.twitch.tv/) откройте **Настройки → Трансляция** и скопируйте основной ключ потока. В StreamBridge выберите Twitch, автоматический сервер, вставьте ключ в поле **Ключ трансляции**, нажмите **Сохранить ключ** и сохраните настройки. Этот вариант не подключает API-функции и чат.

Официальные сведения: [регистрация Twitch](https://dev.twitch.tv/docs/authentication/register-app/), [Public и вход по коду](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow). Шаги в StreamBridge соответствуют текущему коду; вход с вашим конкретным Client ID требует проверки на вашем аккаунте.
